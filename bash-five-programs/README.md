# Progetto: Build Five Programs (freeCodeCamp)

Questo è il mio progetto finale per il modulo Bash Scripting di freeCodeCamp. 
Contiene 5 programmi interattivi che lavorano insieme:

1. `five.sh`: Il file principale che esegue in ordine tutti gli altri script.
2. `questionnaire.sh`: Un questionario interattivo.
3. `countdown.sh`: Un timer che esegue un conto alla rovescia.
4. `bingo.sh`: Un generatore casuale di numeri per il Bingo.
5. `fortune.sh`: Un "indovino" che risponde a domande sì/no.
